# St. Anne High School ETC EOS Archive
ETC EOS show files for St. Anne Catholic High School in Belle River, ON, Canada.

Information can be found on our [Google Doc](https://docs.google.com/document/d/1vXy7nuzBHffpBWG129OyihJlPDN1AI_Onx1MbkwKh5I/edit?usp=sharing), as well as full [changelogs](https://docs.google.com/document/d/1vXy7nuzBHffpBWG129OyihJlPDN1AI_Onx1MbkwKh5I/edit?tab=t.6weyh1fgevmu).

## Legacy Versions
Legacy versions are show files that do not use version codes. To keep uploads in the right order, version codes have been added retroactively.

For changelogs, head [here](https://docs.google.com/document/d/1vXy7nuzBHffpBWG129OyihJlPDN1AI_Onx1MbkwKh5I/edit?tab=t.0).

## Test Versions
Testing versions are concept show files, used to test new ideas. Because not all changes make it into the main branch, changelogs are not guaranteed.
